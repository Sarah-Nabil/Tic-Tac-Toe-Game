### 🎮 Tic-Tac-Toe Game | C# Windows Forms

A **C# Windows Forms desktop application** that implements the classic Tic-Tac-Toe game through an interactive 3×3 game board.

**Key Features:**
- ❌ Alternate turns between X and O.
- 🏆 Detect winning combinations across rows, columns, and diagonals.
- 🤝 Identify draw situations when the board is full.
- 🎨 Highlight the winning cells.
- 🔄 Restart the game and reset the board.
- 💬 Display game results and invalid-move messages.

**Technologies:** C#, Windows Forms, Event Handling, PictureBox Controls, Methods, Enums, and Structs.

This project helped me practice event-driven programming, managing game state, handling UI events, and implementing game logic in a desktop application.
